\subsection{Overview}

We begin by reviewing our problem statement. We wish to determine if $\CGrid$ is universal. If this is true, by Theorem \ref{thm:cgraph-vertex-minor-cgrid}, the family of all circle graphs is universal, and by Theorem \ref{thm:rank-width-vertex-minor-cgrid}, so is any family of resource states with unbounded rank-width. At the same time, Theorem \ref{thm:cgrid-efficiently-simulable} tells us that such universality cannot be efficient. If the comparability grid is not universal, by the same theorems it follows that no family consisting only of circle graphs is universal and unbounded rank-width is a necessary (by Theorem \ref{thm:measure-for-universal}) but not sufficient condition for universality (strengthening a result from \cite{circle-graphs}).

As we will see in Section \ref{sec:conclusions}, there is reason to believe that $\CGrid$ is universal. The evidence is in the form of an of inductive construction. Explicitly, an inductive construction is a description, given a target output state $\ket\phi$ on $n$ qubits, consisting of a vertex minor $H$ of the comparability grid and a measurement pattern on $H$ that generates $\ket\phi$. It has been computationally verified that these inductive constructions yield $n$-qubit universality, for small values of $n$. However, it remains open whether these constructions hold for all $k \in \N$. 

In this section, we develop some algorithmic machinery that may be used to create and test inductive constructions. Concretely, we present algorithms that answer the following questions:
\begin{enumerate}
    \item Given a graph $G$, is it an induced subgraph of some $\CGrid$? Conversely, does there exist induced $\CGrid$-subgraphs with $k$ vertices that satisfy some property $P$? Algorithms for these questions are presented in Section \ref{sec:subgraph-alg}.
    \item Given an induced subgraph $G$ of some $\CGrid$, it can be represented as a quantum gate $\cG$ parametrized by the measurement planes chosen on every vertex. How can we compute this $\cG$? Furthermore, can we compute any sequence of $\cG$s through MBQC on some $\CGrid$? Said another way, can $G$ be tessellated in $\CGrid$, such that we may interpret this tesselation as a sequence of $\cG$ gates on the same set of qubits? Conversely, given a quantum circuit $C$, does there exist a graph state $\ket G$ and a set of measurement plans on its vertices that implement $C$? \end{enumerate}
